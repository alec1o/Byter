<details><summary>📄 <strong><sup><sub>Writer</sub></sup></strong></summary>

### Constructor

- ###### () :                      ``Writer`` <br><sub>Crear instancia con búfer interno vacío</sub>
- ###### (``Writer`` writer) :     ``Writer`` <br><sub>Crear instancia y copiar el búfer de <i>(Writer)</i> como búfer interno</sub>
- ###### (ref ``Writer`` writer) : ``Writer`` <br><sub>Crear instancia y copiar el búfer de <i>(ref Writer)</i> como búfer interno</sub>

### Propiedades

- ###### Length :   ``int`` <br><sub>Devuelve la longitud del búfer.</sub>

### Métodos

- ###### Write(T value) :   ``void`` <br><sub>Escribir contenido en el búfer interno</sub>
- ###### GetBytes() :     ``byte[]`` <br><sub>Devuelve el búfer de la instancia <i>(Writer)</i> como <i>byte[])</i> </sub>
- ###### GetList() :  ``List<byte>`` <br><sub>Devuelve el búfer de la instancia <i>(Writer)</i> como <i>List&lt;byte&gt;</i> </sub>
- ###### Clear():           ``void`` <br><sub>Limpia el búfer interno de la instancia <i>(Writer)</i></sub>

</details>
<details><summary>📄 <strong><sup><sub>Reader</sub></sup></strong></summary>

### Constructor

- ###### (``byte[]`` buffer) :     ``Reader`` <br><sub>Crear instancia usando <i>(Byte[])</i> como búfer interno</sub>
- ###### (``Writer`` writer) :     ``Reader`` <br><sub>Crear instancia usando <i>(Writer)</i> como búfer interno</sub>
- ###### (ref ``Writer`` writer) : ``Reader`` <br><sub>Crear instancia usando <i>(ref Writer)</i> como búfer interno</sub>

### Propiedades

- ###### Success : ``bool`` <br><sub>Devuelve true si la deserialización fue exitosa.</sub>
- ###### Position : ``int`` <br><sub>Devuelve el índice de lectura actual.</sub>
- ###### Length :   ``int`` <br><sub>Devuelve la longitud del búfer.</sub>

### Métodos

- ###### Seek(``int`` position) :                    ``void`` <br><sub>Mover posición (índice del búfer interno)</sub>
- ###### Read<``T``>() :                                ``T`` <br><sub>Leer contenido desde el búfer interno.</sub>
- ###### Read<``string``>(``Encoding`` encoding) : ``string`` <br><sub>Leer cadena con codificación personalizada.</sub>

</details>
<details><summary>📄 <strong><sup><sub>Ejemplo</sub></sup></strong></summary>

- ###### Writer
    ```csharp
    using Byter;
    
    Writer w = new();
    
    // write data
  
    w.Write("Powered by ALEC1O");
    w.Write("由 ALEC1O 提供支持", Encoding.UTF32);
    w.Write((int)1000000);` // 1.000.000
    w.Write((char)'A');
    w.Write((long)-1000000000); // -100.0000.000
    w.Write((byte[])[0, 1, 2, 3]);
    
    // Float(1|2|3) only available in version 2
    w.Write(new Float2(-100F, 300F));
    w.Write(new Float3(-100F, 300F, 600F));
    w.Write(new Float4(-100F, 300F, 600F, 900F));
    
    // get buffer
    
    byte[] buffer = w.GetBytes();
    
    // example send buffer
    Magic.Send(buffer);
    ```
- ###### Reader
    ```csharp
    using Byter;
    
    // example receive buffer
    byte[] buffer = Magic.Receive();
    
    // create instance
    Reader r = new()
        
    // read data
    
    string noticeInEnglish = r.Read<string>(); // Powered by ALEC1O
    string noticeInChinese = r.Read<string>(Encoding.UTF32); // 由 ALEC1O 提供支持
    int myInt = r.Read<int>(); // 1.000.000
    char myChar = r.Read<char>(); // 'A'
    long myLong = r.Read<long>(); // -100.0000.000
    byte[] myBytes = r.Read<byte[]>(); // [0, 1, 2, 3]
    
    // Float(1|2|3) only available in version 2
    Float2 myFloat2 = r.Read<Float2>(); // [x: -100F] [y: 300F]
    Float3 myFloat3 = r.Read<Float3>(); // [x: -100F] [y: 300F] [z: 600F]
    Float4 myFloat4 = r.Read<Float4>(); // [x: -100F] [y: 300F] [z: 600F] [w: 900F]
    
    if (r.Sucess)
    {
        // sucess on read all data
    }
    else
    {
        // one or more data isn't found when deserialize. Might ignore this buffer!
    }
    ```

- ###### Técnica de lectura dinámica
    ```csharp
    var r = new Reader(...);
    
    var topic = r.Read<string>(Encoding.ASCII);
    
    if(!r.Sucess) return; // ignore this 
    
    if (topic == "login")
    {
        string username = r.Read<string>(Encoding.UTF32);
        string password = r.Read<string>(Encoding.ASCII);
        
        if (!r.Sucess) return; // ignore this
        // login user...
    }
    else if(topic == "get user address")
    {
        ulong userId  = r.Read<ulong>();
        string token = r.Read<string>(Encoding.ASCII);
        
        if (!r.Sucess) return; // ignore this
        // get user adress...
    }
    ...
    else
    {
        // ignore this. (Topic not found)
    }
    ```

##### Sobrecarga <sup><i>(lista de tipos compatibles)</i></sup>

> <sub>Información de sobrecarga de Byter</sub>

| <sub>Tipo</sub>       | <sub>Primitive <i>(sobrecarga + tamaño = total)</i></sub>                                 | <sub>Writer/Reader <i>(sobrecarga + tamaño = total)</i></sub>                            |
|-----------------------|---------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------|
| <sub>Bool</sub>       | ✔️  <i>(1 + 1 = 2 bytes)</i>                                                          | ✔️ <i>(2 + 1 = 3 bytes)</i>                                                          |
| <sub>Byte</sub>       | ✔️  <i>(1 + 1 = 2 bytes)</i>                                                          | ✔️ <i>(2 + 1 = 3 bytes)</i>                                                          |
| <sub>SByte</sub>      | ✔️  <i>(1 + 2 = 2 bytes)</i>                                                          | 🚫                                                                                   |
| <sub>Char</sub>       | ✔️  <i>(1 + 2 = 3 bytes)</i>                                                          | ✔️ <i>(2 + 2 = 4 bytes)</i>                                                          |

- <strong><sub>Concatenar bytes (byte[])</sub></strong>
    ```csharp
    byte[] part1 = [ 1, 1, 1 ];
    byte[] part2 = [ 4, 4, 4 ];
    
    /* 
        ..          ..      ..      ..      ..      ..      ..      ..      ..      .. 
        
        Concat part1 and part2 
        
        ..          ..      ..      ..      ..      ..      ..      ..      ..      .. 
        
        --- `byte[].Concat` Used concat bytes normally.
        --- `byte[].ConcatInverse` Used concat bytes inversed (first is last and last is first).
        --- `byte[].Concat(invert: true|false, ....)` Generic way to concat `Inversed` and `Normal` direction.
        
        ..          ..      ..      ..      ..      ..      ..      ..      ..      .. 
    */
    
    
    // Normal >>>
    byte[] normal = part1.Concat(part2); //... [ 1, 1, 1, 4, 4, 4 ]
    byte[] normal = part2.Concat(invert: true, part1); //... [ 1, 1, 1, 4, 4, 4 ]
    byte[] normal = byte[].Concat(invert: true, part2, part1); //... [ 1, 1, 1, 4, 4, 4 ]
    byte[] normal = byte[].Concat(invert: false, part1, part2); //... [ 1, 1, 1, 4, 4, 4 ]  
    
    // Inversed <<<
    byte[] inversed = part1.ConcatInverse(part2); //... [ 4, 4, 4, 1, 1, 1 ]
    byte[] inversed = part2.Concat(invert: false, part1); //... [ 4, 4, 4, 1, 1, 1 ]
    byte[] inversed = byte[].Concat(invert: false, part2, part1); //... [ 4, 4, 4, 1, 1, 1 ]
    byte[] inversed = byte[].Concat(invert: true, part1, part2); //... [ 4, 4, 4, 1, 1, 1 ]
    ```

# Byter

Byter es un serializador de bytes. Puede serializar y deserializar desde tipos primitivos.

> ###### Byter es muy estable, súper fácil de aprender, extremadamente rápido y económico (2 bytes o ``sizeof(char)`` de sobrecarga por dato escrito) y está ``100%`` escrito en ``C#`` ¡y es GRATUITO!

- #### ``Success``
    ```cs
    using Byter;

    byte[] buffer = ...;
    var r = new Reader(buffer);
    string name = r.Read<string>();
    int age = r.Read<int>();
    
    // devuelve true si no existe problema al leer los valores.
    // devuelve false cuando hay algún error al leer los valores;
    bool success = r.Success; 
    ```
    - ###### ADVERTENCIA
      Internamente, antes de escribir datos se agrega un prefijo al frente, por lo que al leer siempre compara el prefijo
      del (tipo de datos) que deseas leer con las cadenas en el búfer de lectura. Si los prefijos no coinciden entonces (
      Reader. Success = False), por ejemplo. Si escribes un (int) e intentas leer un float (Reader.Success = False) porque el
      prefijo de un (int) es diferente al de un (float), se recomienda leer todos los datos y al final
      verificar el éxito, si es (Reader.Success = False) entonces uno o más datos están corruptos. Esto significa que Writer y
      Reader agregan validación a tus datos escritos y leídos.

<br/>

> Métodos

- #### ``Read<T>()`` ``Read<string>(Encoding encoding)``;
  ```cs
  using Byter;

  byte[] buffer = ...;

  // Crear instancia de lector
  using r = new Reader(buffer);

  string name = r.Read<string>();
  char firstLatter = r.Read<char>();
  Float3 position = r.Read<Float3>();

  // Verificar si es exitoso
  if (r.Success)
  {
      Console.WriteLine($"Name: {name}");
      Console.WriteLine($"First Latter: {firstLatter}");
      Console.WriteLine($"Position: {position}");
  }
  else
  {
      Console.WriteLine("Error on get data");
  }
  ```

- #### ``Seek(int position)``;
  ```cs
  using Byter;

  using var w = new Writer();
  w.Write("KEZERO");
  w.Write((int) 1024);

  using var r = new Reader(ref w);

  string name = r.Read<string>(); // name: KEZERO
  int age = r.Read<int>(); // age: 1024
  
  // Mover índice (Reader.Position) al valor objetivo "EL VALOR MÍNIMO ES 0";
  r.Seek(10); // move current index for read for 10 (when start read using .Read<Type> will start read on 10 index from buffer);

  // Restablecer posición interna
  r.Seek(0);

  string name2 = r.Read<string>(); // name: KEZERO (because the start index of this string on buffer is 0)
  int age2 = r.Read<int>(); age: 1024;

  // NEED READ LAST INT
  r.Seek(r.Position - sizeof(int) + sizeof(char) /* int size is 4 + char size is 2. The 2 bytes is overhead of protocol */);    
  int age3 = r.Read<int>(); age: 1024 (because i return 4bytes before old current value)
  ```

#### Ejemplo

```csharp
using Byter;

// writing
Writer writer = new();

writer.Write(1000); // index
writer.Write("{JSON}"); // content
writer.Write(new byte[]{ 1, 1, 1, 1 }); // image

// geting buffer
byte[] buffer = writer.GetBytes();
writer.Dispose(); // Destroy Writer

// reading
Reader reader = new(buffer);

int index = reader.Read<int>();
string json = reader.Read<string>();
byte[] image = reader.Read<byte[]>();

// Check error
if (!reader.Success) // IS FALSE
{
    Console.WriteLine("*** ERROR ****");
    return;
}

// Check success
Console.WriteLine("*** SUCCESS ****");      

// Output
Console.WriteLine($"Index: {index}");           // output: 1000
Console.WriteLine($"JSON : {json }");           // output: JSON
Console.WriteLine($"Image: {image.Length}");    // output: 4
Console.WriteLine($"Status: {reader.Success}"); // output: True

// Making error
float delay = reader.Read<float>();
                                                                                            /*
WARNING:                
if you reverse the reading order or try to read more data than added (Reader.Succes = False),
Remembering does not return exception when trying to read data that does not exist it just
returns the default construction, and (Reader.Success) will be assigned (False)             */

if (reader.Success)  // IS FALSE, THE IS NOT WRITED IN BUFFER
    Console.WriteLine($"Delay: {delay}");
else                // IS TRUE, THE DELAY NOT EXIST
    Console.WriteLine($"Delay not exist");

// Output of status
Console.WriteLine($"Status: {reader.Success}"); // output: False

reader.Dispose(); // Destroy Reader
```
